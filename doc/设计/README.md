## 文档内容

设计文档涵盖以下内容：

1. **技术选型** — Vue 3 + Vite、Vue Router（Hash）、IndexedDB + Dexie.js、PWA、三方库清单
2. **架构设计** — 整体架构、路由方案、状态管理、页面结构、组件分层、原型图、分页导航
3. **数据模型设计** — 8张表结构（ingredients/dishes/dish_ingredients/favorites/browsing_history/learning_progress/notes/images）、详细字段定义、菜品多维度标签(tags)、图片存储策略
4. **数据关系图** — ER 图展示 8 张表之间的关联关系与级联行为
5. **类设计** — Dexie Models（数据层）、Pinia Stores（状态层）、组件结构（视图层）
6. **数据流转设计** — 9个核心流程图：初始化、CRUD、双向关联、浏览记录、个人备注、导出导入、学习进度、食材匹配、图片上传
7. **兼容性策略** — 目标平台（Chrome/Edge + Android）、关键技术决策、移动端适配
8. **部署方案** — GitHub Pages 配置、PWA 配置、数据导出导入实现
9. **界面风格规范** — 色彩体系、字体规范、间距体系、圆角阴影、组件样式、导航设计、图标、动效
10. **开发里程碑** — 7 个阶段
