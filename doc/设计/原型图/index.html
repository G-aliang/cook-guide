食材库 / 蔬菜 / 🍅 番茄
① 介绍
番茄（Tomato），茄科番茄属浆果，富含番茄红素和维生素C。既是蔬菜也是水果，口感酸甜多汁。
② 品种
大番茄个大肉厚，适合炒蛋
圣女果甜度高，适合凉拌
普罗旺斯沙瓤绵密，适合炖煮
③ 购买/挑选
看颜色均匀有光泽 · 摸手感有弹性 · 闻气味有清香 · 价格 3-6元/斤
④ 储存
常温3-5天，阴凉处
冷藏7-10天，口感会变
冷冻数月，适合做汤
⑤ 处理
清洗 → 去蒂 → 去皮(烫皮法/火烤法) → 切片/切块 → 出沙技巧 → 去籽
⑥ 相关菜品

⑦ 营养成分
热量18 kcal/100g
脂肪0.2g
蛋白质0.9g
碳水3.9g
✅ 低热量，富含维C，适合减脂期
⑧ 个人备注
