## 文档内容

开发计划涵盖以下内容：

1. **总体计划** — 8 个 Phase 总览、开发原则、依赖关系
2. **Phase 1: 基础设施搭建** — 项目初始化、路由、数据层、CSS 框架
3. **Phase 2: 食材模块** — 列表、详情（8模块）、增删改
4. **Phase 3: 菜品模块** — 多维度筛选、详情、增删改、级联删除
5. **Phase 4: 双向关联 + 选菜匹配** — 关联导航、匹配算法、匹配结果
6. **Phase 5: 个人中心** — 收藏、浏览记录、学习进度、设置
7. **Phase 6: 图片与视频** — 上传、展示、视频链接
8. **Phase 7: 初始数据填充** — 100+ 食材、500+ 菜品数据收集策略
9. **Phase 8: 部署上线** — GitHub Pages、PWA 配置
10. **全局验证清单** — 功能/数据/响应式/性能/安全/部署全面检查
