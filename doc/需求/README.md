# 需求文档

本目录存放项目的需求规格文档，描述用户需要什么（"做什么"）。

## 文档列表

| 文档 | 说明 | 版本 |
|------|------|------|
| [需求文档.md](需求文档.md) | 完整的用户需求规格，含功能需求、内容规划、视觉要求、数据要求 | v2.0 |

## 文档内容

需求文档涵盖以下内容：

1. **项目概述** — 定位、核心价值、使用场景
2. **功能需求** — 食材模块（8大信息体系）、菜品模块、双向关联导航、搜索、收藏、购物清单、学习进度、个人备注、数据管理
3. **内容规划** — 食材分类体系（9大类）、菜品分类体系、初始内容清单（100+食材、100+菜品）
4. **视觉设计要求** — 清新简约风、色彩方案、响应式要求、字体
5. **数据要求** — 存储、导出、导入、同步、安全

> 技术实现方案见 [设计文档](../设计/设计文档.md)
