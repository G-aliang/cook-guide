## 一、项目概述

### 1.1 项目定位

一个**个人使用的家常菜入门指南网页应用**，帮助厨房新手系统化地学习做菜全流程——从认识食材、购买、储存、处理，到完整菜品的制作。核心特色是**菜品与食材的双向关联导航**，让用户无论从"想做的菜"还是"手头的食材"出发，都能快速找到相关信息。

### 1.2 核心价值

- **双向关联**：想做菜 → 查食材；有食材 → 查菜谱
- **新人友好**：内容通俗，流程分步，降低入门门槛
- **个人专属**：可自由增删改，打造属于自己的厨房知识库
- **本地存储**：数据存在浏览器本地，不依赖网络，隐私安全
- **随身可用**：手机安装后像 App 一样使用，支持离线

### 1.3 使用场景

| 场景 | 描述 |
|------|------|
| 想做某道菜 | 打开菜品详情页，查看所需食材、购买要点、处理方式、制作步骤 |
| 买了新食材不知道怎么用 | 打开食材详情页，查看能做哪些菜，挑一道试试 |
| 不知道做什么菜 | 打开选菜匹配页，勾选手头食材，一键匹配可做的菜谱 |
| 学习记录 | 标记做过的菜，记录学习进度，逐步积累厨艺 |
| 随手记心得 | 用某个食材或做某道菜后，记录心得体会，方便以后回顾 |
| 找回看过的内容 | 个人中心浏览记录，快速找到之前看过的菜品或食材 |

## 二、功能需求

### 2.1 食材模块

食材是整个应用的基础。每种食材不是简单的一段话介绍，而是一个完整的知识体系，覆盖**认识 → 挑选 → 储存 → 处理 → 烹饪**的全链路。

#### 食材列表

- 按分类浏览食材
- 搜索食材名称
- 每条展示：名称、分类标签、简介摘要

#### 食材详情（8 大信息模块）

点击某个食材（比如西红柿），希望看到以下完整信息：

---

**① 介绍**

这个食材是什么、基本特性、营养价值、在烹饪中的角色（主料/辅料/调味）。

**顶部展示食材图片**（用户上传的实拍图，初始用 emoji 占位）。

示例（西红柿）：番茄（Tomato），茄科番茄属浆果，富含番茄红素和维生素C。既是蔬菜也是水果，在中式烹饪中常作主料或配菜，口感酸甜多汁。

---

**② 品种**

列出常见品种及各自特点、适用场景。

示例（西红柿）：

| 品种 | 特点 | 适合做法 |
|------|------|----------|
| 大番茄（普通番茄） | 个大、肉厚、汁多酸甜 | 番茄炒蛋、番茄汤、红酱 |
| 圣女果（小番茄） | 个小、甜度高、皮薄 | 凉拌、沙拉、点缀 |
| 普罗旺斯番茄 | 沙瓤、口感绵密、甜度高 | 生吃、番茄牛腩 |
| 黑珍珠番茄 | 紫黑色、花青素高、酸甜浓郁 | 高端料理、酱汁 |

---

**③ 购买/挑选**

挑选要点：看什么、摸什么、闻什么。价格参考。避坑提示。

示例（西红柿）：

| 维度 | 要点 |
|------|------|
| 看颜色 | 表面颜色均匀、有光泽，全红为佳，不要青红不均 |
| 看形状 | 圆润饱满，无凹陷、无裂痕 |
| 摸手感 | 有弹性但不软塌，太硬可能未熟，太软可能过熟 |
| 闻气味 | 成熟的番茄有淡淡的清香 |
| 看蒂部 | 蒂部叶片鲜绿、有毛刺感为新鲜 |
| 避坑 | 避免选催熟的（颜色均匀但手感硬、无香气） |
| 价格 | 普通番茄约 3-6 元/斤，圣女果约 10-20 元/斤 |

---

**④ 储存**

按储存方式分场景说明，覆盖常温/冷藏/冷冻/遮光等。不同食材有不同最佳储存方案。

示例（西红柿）：

| 储存方式 | 温度/条件 | 保质期 | 注意事项 |
|----------|-----------|--------|----------|
| 常温 | 室内阴凉处（15-25℃） | 3-5 天 | 未熟番茄可放常温催熟，**不要放冰箱**（低温会破坏风味和口感） |
| 冷藏 | 冰箱冷藏室 4℃ | 7-10 天 | 已熟透的可短期冷藏，但取出后尽快食用，口感会变 |
| 冷冻 | 冰箱冷冻室 -18℃ | 数月 | 适合做汤/酱用：洗净切块装密封袋冷冻，解冻后煮汤不影响 |
| 加工保存 | 制成番茄酱/罐头 | 数月 | 自制番茄酱可冷藏保存 1 周，冷冻可存数月 |
| 遮光 | 避免阳光直射 | — | 番茄放在阳光下会加速变软腐烂，放在阴凉处 |

---

**⑤ 处理**

从清洗到预处理的完整操作指南。针对新人，步骤要具体到"怎么做"。

示例（西红柿）：

| 处理步骤 | 具体操作 |
|----------|----------|
| 清洗 | 流水冲洗表面，可用淡盐水浸泡 5 分钟去残留 |
| 去蒂 | 用刀在蒂部划十字，挖去硬芯 |
| 去皮（可选） | **烫皮法**：顶部划十字，沸水烫 15-20 秒，捞出立即入冷水，皮即可轻松撕下 |
| 去皮（可选） | **火烤法**：用叉子插住，明火烤至表皮起泡发焦，剥皮后有烟熏味 |
| 切法 | 切片/切块/切丁，按菜品需求选择 |
| 出沙技巧 | 炒番茄时先加盐炒出汁，小火慢炒至浓稠沙状，再加其他食材 |
| 去籽（可选） | 切片后用勺刮去籽和汁，适合做酱 |

---

**⑥ 相关菜品**

列出所有使用该食材的菜品，按难度或分类排列，点击跳转到菜品详情页。

示例（西红柿）：
- 🍅 番茄炒蛋（入门）
- 🍅 番茄牛腩（进阶）
- 🍅 罗宋汤（进阶）
- 🍅 意式番茄酱（入门）

---

**⑦ 营养成分**

每 100g 的营养数据 + 健康提示。

示例（西红柿）：

| 指标 | 含量（每100g） |
|------|----------------|
| 热量 | 18 kcal |
| 脂肪 | 0.2g |
| 蛋白质 | 0.9g |
| 碳水化合物 | 3.9g |
| 膳食纤维 | 1.2g |
| 钠 | 5mg |

> 健康提示：低热量、富含番茄红素和维生素C，适合减脂期食用。

---

**⑧ 个人备注**

记录自己使用时的心得体会。支持多条备注，按时间倒序排列。可随时新增、编辑、删除。手机端/电脑端均可操作。

示例：
- "今天买的番茄特别新鲜，沙瓤很明显，炒蛋超好吃"
- "这种番茄偏酸，做汤的时候多放点糖"
- "冷冻的番茄做汤不影响口感，推荐"

---

#### 食材增删改

- 新增食材：填写上述 8 大模块所有信息
- 编辑食材：修改任意字段
- 删除食材：需二次确认，提示关联菜品数量（个人备注将一并删除）

### 2.2 菜品模块

#### 菜品多维度分类体系

每道菜可以同时属于多个分类维度，每个维度下可打多个标签。分类维度如下：

| 维度 | 说明 | 示例标签 |
|------|------|----------|
| **烹饪方式** | 按做菜方法分类 | 蒸、煮、炒、卤、烤、炸、烘焙、煎、炖、焖、拌、焗 |
| **荤素/场景** | 按荤素或食用场景分类 | 荤菜、素菜、下酒菜、宝宝辅食、减脂餐、低卡、高蛋白 |
| **菜系/地域** | 按菜系或地域分类 | 家常菜、东北菜、山西菜、川菜、粤菜、湘菜、江浙菜、西北菜 |
| **菜品类型** | 按菜品大类分类（主分类） | 凉菜、热炒、汤羹、主食、甜点 |
| **用餐时段** | 按适合的用餐时间分类 | 早餐、午餐、晚餐、夜宵 |
| **自定义标签** | 用户自行添加 | 快手菜、拿手菜、宴客菜、一人食、便当菜... |

> **每个菜品可同时拥有多个维度的标签。** 例如"番茄炒蛋"：烹饪方式=炒、荤素=素、菜系=家常、类型=热炒、时段=早/午/晚、自定义=快手菜、拿手菜。

#### 菜品列表

- 按主分类浏览（凉菜、热炒、汤羹、主食、甜点）
- 按难度筛选（入门/进阶/挑战）
- **按任意维度筛选**：烹饪方式、荤素/场景、菜系/地域、用餐时段、自定义标签
- 搜索菜品名称
- 每条展示：名称、主分类标签、难度标签、各维度标签、预估时长、缩略描述、热量参考
- 卡片上显示热量参考（如"约 250 kcal/份"）

**筛选交互：**
- 主分类和难度作为顶部标签栏
- 其他维度作为二级筛选器（可多选），如"烹饪方式：蒸 | 炒 | 炖"
- 筛选结果实时更新

#### 菜品详情

| 信息块 | 内容 |
|--------|------|
| 基本信息 | 名称、主分类、难度、预估时长、简介、**菜品成品图** |
| 分类标签 | 展示该菜品所有维度的标签，可点击跳转到对应筛选结果 |
| 食材清单 | 所需食材列表（含用量，食材可点击跳转详情） |
| 制作步骤 | 分步说明，每步可附**步骤图片**和**视频链接** |
| 营养信息 | 每份热量/脂肪/蛋白质/碳水等 + 健康提示 |
| 个人备注 | 记录做这道菜的心得（多条，可增删改，可附带**成品照片**） |
| 相关食材 | 点击跳转食材详情页 |

#### 菜品增删改

- 新增菜品：填写上述所有信息，至少关联 1 个食材，可设置各维度标签
- 编辑菜品：修改任意字段，包括各维度标签
- 删除菜品：需二次确认，提示将同时移除关联记录和个人备注

### 2.3 双向关联导航

这是整个应用的灵魂。

- **菜品 → 食材**：菜品详情页的"食材清单"中，每个食材可点击跳转到该食材详情页
- **食材 → 菜品**：食材详情页的"相关菜品"区域，列出所有使用该食材的菜品，点击跳转
- 关联自动维护：新增/编辑菜品时勾选食材，删除食材时提示影响范围

```
菜品详情页 ←──关联──→ 食材详情页
```

---

### 2.4 食材匹配推荐

从"有什么食材 → 能做什么菜"出发，让用户批量勾选食材，一键匹配可用菜谱。

**用户流程：**

```
打开"选菜匹配"页 → 从分类标签云中点击食材加入"已选" → （可选）输入自定义食材
→ 点击"匹配菜谱" → 跳转到匹配结果页 → 点击某道菜查看详情
```

**匹配逻辑：**

- 优先展示使用**全部**已选食材的菜品（完美匹配）
- 其次展示使用**部分**已选食材的菜品，按匹配数量降序排列
- 每道菜显示匹配度标识："用了 5/5 个食材" 或 "用了 3/5 个食材"

**已选食材区：**

- 展示已选食材标签（可逐个删除）
- "清空"按钮一键清除全部
- 支持手动输入自定义食材（不在预设列表中的）

**分类标签云：**

按食材大分类展示标签云，点击标签即加入已选：

| 分类 | 展示方式 |
|------|----------|
| 蔬菜 | 标签云，点击加入 |
| 肉禽 | 标签云，点击加入 |
| 海鲜水产 | 标签云，点击加入 |
| 蛋奶 | 标签云，点击加入 |
| 豆类 | 标签云，点击加入 |
| 冻品 | 标签云，点击加入 |
| 主食 | 标签云，点击加入 |
| 调味项 | 分组展示（基础调味/香辛料/复合调味） |
| 干货 | 标签云，点击加入 |

**匹配菜谱按钮：**

- 页面顶部和底部各放置一个，方便滚动后操作
- 至少选 1 个食材才能点击（未选时按钮禁用）

**匹配结果页：**

- 顶部展示已选食材标签（可移除某个重新匹配）
- 菜品卡片列表，按匹配度降序排列
- 每张卡片显示：菜名、匹配度（"用了 X/Y 个食材"）、难度、时长、热量
- 底部"重新选菜"按钮返回匹配页

### 2.5 搜索功能

- 全局搜索框（首页顶部）
- 支持按名称搜索菜品和食材
- 搜索结果分类展示（菜品结果 + 食材结果）

### 2.6 收藏功能

- 菜品详情页可收藏/取消收藏
- 首页展示收藏列表入口
- 收藏页展示所有已收藏菜品

---

### 2.7 浏览记录

自动记录用户最近浏览过的菜品和食材，方便快速找回之前看过的内容。

**记录规则：**

- 每次打开菜品详情页或食材详情页时，自动记录一条浏览记录
- 同一菜品/食材在短时间内重复浏览，更新时间而非新增记录
- 最多保留最近 50 条记录，超出后自动删除最早的

**浏览记录页：**

- 按时间倒序排列（最近浏览的在最上面）
- 每条记录显示：类型标签（菜品/食材）、名称、浏览时间
- 点击某条记录可快速跳转到对应的详情页
- 支持左滑删除单条记录
- 支持清空全部浏览记录 |

---

### 2.8 学习进度

- 菜品详情页可标记"已做过"/"想做"
- 首页展示学习进度概览（已做 X 道，想做 Y 道）
- 学习进度页：已做过列表、想做列表
- 可备注每次做菜的感受/改进

---

### 2.9 个人备注

在食材详情页和菜品详情页均可记录个人使用心得，打造专属的厨房日记。

| 能力 | 说明 |
|------|------|
| 多条备注 | 每个食材/菜品可记录多条备注，按时间倒序排列 |
| 自由编辑 | 可随时新增、编辑、删除任意一条备注 |
| 跨端使用 | 手机端和电脑端均可操作 |
| 字数限制 | 每条备注 500 字以内，支持换行 |

**使用场景：**

| 场景 | 位置 | 示例内容 |
|------|------|----------|
| 食材心得 | 食材详情页 | "今天买的番茄特别新鲜，沙瓤很明显" |
| 食材处理技巧 | 食材详情页 | "烫皮时间别超过20秒，不然果肉会烫烂" |
| 做菜复盘 | 菜品详情页 | "第一次做太咸了，下次生抽减半" |
| 家人反馈 | 菜品详情页 | "老公说这道菜比餐厅做的还好吃" |
| 改进计划 | 菜品详情页 | "下次试试加一点糖，中和酸味" |

**交互要求：**

- 食材/菜品详情页底部固定"个人备注"区域
- 输入框 + 提交按钮，简洁直接
- 备注列表展示时间戳 + 内容
- 每条备注支持编辑（内联编辑）和删除
- 手机端：备注区域在页面底部，输入框固定可见
- 电脑端：备注区域在右侧栏或正文底部

### 2.10 设置

**版本管理：**

- 显示应用版本号（如 v1.0.0）
- 显示更新日期
- 可查看版本更新说明

**数据管理：**

- 一键导出全部数据（JSON 格式），用于备份或跨设备迁移
- 从 JSON 文件导入数据，可选择覆盖或合并到当前数据
- 导入前需确认，避免误覆盖
- 重置数据（清空所有内容，恢复初始状态）

> 说明：数据存储在各设备的浏览器本地，各设备独立。跨设备同步通过"导出 → 传输 → 导入"完成。

### 2.11 图片与视频功能

为食材、菜品、步骤和备注提供图片展示和上传能力，视频使用外部链接。

#### 图片支持范围

| 实体 | 图片位置 | 说明 |
|------|----------|------|
| 食材 | 介绍模块顶部 | 食材实拍图，1 张主图 |
| 菜品 | 基本信息模块顶部 | 菜品成品图，1 张主图 |
| 制作步骤 | 每个步骤下方 | 步骤操作图，每步可选 1 张 |
| 个人备注 | 备注内容中 | 成品照片等，每条备注最多 3 张 |

#### 图片来源

- **初始数据**：使用 emoji 占位符，不预置真实图片
- **用户上传**：在编辑食材/菜品时上传图片，或在备注中附带照片
- **手机端**：调用相机拍照或从相册选择
- **电脑端**：文件选择器选择图片

#### 图片上传交互

| 入口 | 操作 |
|------|------|
| 食材编辑页 | 点击"上传图片" → 选择文件 → 预览 → 确认 |
| 菜品编辑页 | 主图上传 + 每个步骤可单独上传图片 |
| 备注输入区 | 点击"📷"按钮 → 选择图片 → 预览 → 提交 |

**上传限制：**

| 限制项 | 值 |
|--------|----|
| 单张图片大小 | ≤ 500KB |
| 食材图片 | 1 张主图 |
| 菜品图片 | 1 张主图 + 每步骤可选 1 张 |
| 备注图片 | 每条 ≤ 3 张 |
| 支持格式 | JPG / PNG / WebP |

#### 视频支持

视频使用**外部链接**，不存储视频文件本身。

| 位置 | 说明 |
|------|------|
| 菜品基本信息 | 可填入视频链接（如 bilibili、YouTube 等） |
| 制作步骤 | 每个步骤可附视频链接 |

**视频链接要求：**

- 支持嵌入播放的平台链接（如 bilibili、YouTube、腾讯视频等）
- 以 URL 形式存储在数据中
- 详情页展示时，支持点击播放（内嵌播放器或跳转到平台）
- 导出 JSON 时，视频链接自然包含在内，不会丢失

#### 图片展示

| 场景 | 展示方式 |
|------|----------|
| 食材/菜品列表卡片 | 显示缩略图（如无图片则显示 emoji 占位） |
| 食材/菜品详情页 | 顶部大图展示 |
| 步骤区域 | 步骤文字下方展示步骤图 |
| 备注列表 | 备注文字旁展示缩略图 |

#### 数据导出/导入

- 图片以 base64 格式随 JSON 一起导出/导入，不会丢失
- 视频链接为 URL 字符串，自然包含在 JSON 中
- 导出文件体积会变大（图片 base64 膨胀约 33%），导出时提示用户文件大小
- 导入时图片和视频链接一并恢复

## 四、视觉设计要求

### 4.1 设计风格

清新简约风，参考大众点评/下厨房的清爽感。浅色背景、圆角卡片、留白充足、字体清晰。

### 4.2 色彩方案

- 主色：温暖的橙色或绿色系（与美食相关）
- 背景：浅色（白色/浅灰）
- 文字：深灰/黑色
- 卡片：白色背景 + 轻阴影 + 圆角

### 4.3 响应式要求

| 断点 | 设备 | 布局 |
|------|------|------|
| ≥ 1024px | 桌面 | 多列卡片布局，顶部导航栏 |
| 768-1023px | 平板 | 2 列卡片，顶部导航栏 |
| < 768px | 手机 | 单列卡片，**底部导航栏**（手指可达性好） |

### 4.4 字体

- 标题：思源黑体 / 系统默认无衬线
- 正文：系统默认无衬线

## 五、数据要求

### 5.1 存储

- 数据存储在本地浏览器中，不依赖网络
- 关闭浏览器或断网后数据不丢失
- 不上传任何服务器，保障隐私

### 5.2 导出

- 支持一键导出全部数据为 JSON 文件
- 包含所有食材、菜品、备注、收藏、浏览记录、学习进度

### 5.3 导入

- 支持从 JSON 文件导入数据
- 导入时可选择覆盖或合并到当前数据
- 导入前需确认，避免误覆盖

### 5.4 同步

- 各设备数据独立存储
- 跨设备同步通过"导出 → 传输 → 导入"完成
- 由于使用频次低，手动同步完全可接受

### 5.5 安全

- 数据完全在本地，不经过任何外部服务器
- 可随时导出备份，不怕数据丢失
- 清除浏览器数据会导致数据丢失，需提前导出备份
